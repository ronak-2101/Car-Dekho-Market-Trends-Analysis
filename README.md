# 🚗 Car Dekho Market Trends Analysis

## 📌 Project Overview

This project analyzes a Car Dekho used-car dataset to explore market trends and understand the factors associated with car selling prices.

The analysis was performed using Python, with a focus on data exploration, statistical analysis, visualization, correlation analysis, and identifying key pricing patterns.

## 🛠️ Tools & Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Google Colab

## 🔍 Analysis Performed

* Dataset exploration and data validation
* Missing-value and duplicate-value analysis
* Descriptive statistical analysis
* Univariate and categorical analysis
* Fuel type analysis
* Seller type analysis
* Transmission analysis
* Selling price analysis
* Present price vs. selling price analysis
* Kilometers driven analysis
* Outlier identification and investigation
* Correlation analysis
* Dashboard visualization

## 📊 Key Findings

* The dataset contains **299 car listings** after removing duplicate records.
* The data covers cars from **2003 to 2018**.
* **Petrol** is the most common fuel type, accounting for approximately **79.4%** of listings.
* **Dealer** listings represent the largest share with **193 cars**.
* **Diesel** cars have the highest average selling price at approximately **₹10 lakh**.
* Automatic cars have a higher average selling price than manual cars in the analyzed dataset.
* **Present Price and Selling Price** show a strong positive correlation of **0.879**.
* **Kms Driven and Selling Price** show an almost negligible correlation of **0.029**.
* The highest selling price recorded is approximately **₹35 lakh**, for a **Land Cruiser**.
